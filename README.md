# Galette Paypal plugin

> [!WARNING]
> PayPal is discontinuing its legacy Website Payments Standard (WPS) integration, with full transaction processing termination scheduled for January 2027.
> This plugin is **not compatible** with any other integration.

[![GitHub license](https://img.shields.io/github/license/galette-plugins/plugin-paypal)](https://github.com/galette-plugins/plugin-paypal/blob/master/COPYING)
[![Maintained by the Galette core team](https://img.shields.io/badge/maintained_by-Galette_core_team-ffb619?style=for-the-badge&logo=php&logoColor=white)](https://galette.eu)

### English

A [Galette](https://galette.eu) plugin to handle paypal payments.

This plugin is developed and maintained by the **Galette core team**, along with Galette itself — unlike most of the plugins hosted in this organization, which are community-maintained.

* website: https://galette-plugins.github.io/plugin-paypal/
* bugs and features: https://bugs.galette.eu/projects/galette-plugin-paypa
* mailing lists:
  * users: https://lists.mailman3.com/postorius/lists/galette-users.mailman3.com/
  * developers: https://lists.mailman3.com/postorius/lists/galette-devel.mailman3.com/
* documentation: https://galette-plugins.github.io/plugin-paypal/documentation.html

To use Galette Paypal plugin, you'll need a reliable Galette version, and of course the plugin itself by either:

* download latest version available from the [releases page](https://github.com/galette-plugins/plugin-paypal/releases)
* use [Galette Paypal plugin source code from repository](https://github.com/galette-plugins/plugin-paypal), this solution requires some technical skills

### Français

Un plugin [Galette](https://galette.eu) pour gérer les paiements de cotisation et de dons via Paypal.

Ce plugin est développé et maintenu par l'**équipe Galette**, comme Galette lui-même — contrairement à la plupart des plugins hébergés dans cette organisation, qui sont maintenus par la communauté.

* site web : https://galette-plugins.github.io/plugin-paypal/
* bogues et fonctionnalités : https://bugs.galette.eu/projects/galette-plugin-paypa
* listes de diffusion :
  * utilisateurs : https://lists.mailman3.com/postorius/lists/galette-users.mailman3.com/
  * développeurs : https://lists.mailman3.com/postorius/lists/galette-devel.mailman3.com/
* documentation : https://galette-plugins.github.io/plugin-paypal/fr/documentation.html

Pour utiliser le plugin Paypal pour Galette, vous aurez besoin d'une version adéquate de Galette, ainsi que du plugin lui-même :

* télécharger la dernière version depuis la [page des versions](https://github.com/galette-plugins/plugin-paypal/releases)
* utiliser [le code source du plugin Paypal pour Galette depuis le dépôt](https://github.com/galette-plugins/plugin-paypal), cette solution requiert quelques compétences techniques
